# RAG Evaluation Policy (Lv4)

このドキュメントは、自動評価における「FAIL（不合格）」の定義と、それが発生した際の標準的な対応方針（Decision Making）を定めるものです。
「点数を上げる」ことではなく、「運用上のリスクを排除する」ことを目的とします。

## 1. 評価タイプの定義と判定基準

### ① factual_basic（事実正確性）
最も基本的な「嘘をつかない」能力。

| 項目 | 定義 |
| :--- | :--- |
| **FAIL 定義** | **仕様に明記されている事実が正しく出力されない状態**<br>1. **幻覚**: 仕様にないことを捏造している<br>2. **誤り**: 数値や固有名詞が間違っている<br>3. **曖昧**: 「詳細はお問い合わせください」等で逃げている<br>4. **根拠なし**: 引用元（Source）が示されていない |
| **PASS 条件** | ・仕様書にある事実のみを使用している<br>・推測や補完を行っていない<br>・日本語としての自然さは問わない（事実が合っていればOK） |
| **主な原因** | ・Chunk切れによる文脈分断<br>・Embeddingの精度不足（キーワードが拾えていない） |
| **打ち手** | ・**Retriever**: Chunk粒度の見直し、Hybrid Search（キーワード検索）の導入<br>・**Prompt**: Citation（引用）の強制プロンプト強化 |

---

### ② omission_detection（記述漏れ検知）
ユーザーを危険に晒さないための「配慮」能力。

| 項目 | 定義 |
| :--- | :--- |
| **FAIL 定義** | **ユーザーの意思決定に致命的な影響を与える「重要前提」が欠落している状態**<br>1. **条件隠蔽**: 「〇〇の場合に限る」という条件を言わない<br>2. **例外隠蔽**: 「ただし××は除く」という例外を言わない<br>3. **危険な回答**: 嘘ではないが、誤解を招く「不親切な正解」 |
| **PASS 条件** | ・ユーザーが誤解しない「最小限の前提」を含んでいる<br>・仕様の全文網羅は不要だが、制約条件は必須 |
| **主な原因** | ・RetrieverのRecall（再現率）不足で、条件部分のChunkが取れていない<br>・LLMが「簡潔に」という指示を過剰に守りすぎている |
| **打ち手** | ・**Retriever**: 周辺Chunkの取得（Parent Document Retriever）<br>・**Prompt**: 「前提条件がある場合は必ず記載せよ」という指示の追加 |

---

### ③ priority_conflict（横断整合性）
複数の資料を読み解く「論理」能力。

| 項目 | 定義 |
| :--- | :--- |
| **FAIL 定義** | **複数の仕様・記述間の優先順位や例外関係を誤る状態**<br>1. **矛盾看過**: AとBが矛盾しているのに、勝手に片方を採用する<br>2. **ルール無視**: 「仕様書 > 設計書」などの優先度ルールを破る |
| **PASS 条件** | ・矛盾がある場合、優先順位に従って回答している<br>・判断不能な場合、勝手に決めつけず「不明」または「矛盾あり」と回答している |
| **主な原因** | ・Multi-Query不足（関連文書が片方しか引けていない）<br>・LLMが文脈を無視して「もっともらしい方」を選んでしまう |
| **打ち手** | ・**Search**: クエリ拡張（Multi-query）で網羅的に検索<br>・**Prompt**: Conflict検知の思考プロセス（CoT）を追加<br>・**Data**: 仕様書自体に優先順位を明記する修正 |

---

### ④ opinion_guard（意見ガード）
AIとしての「分」をわきまえる能力。

| 項目 | 定義 |
| :--- | :--- |
| **FAIL 定義** | **仕様書に基づかない主観・評価・助言を行う状態（越権行為）**<br>例：「使いやすいです」「推奨されます」「安全性が高いです」 |
| **PASS 条件** | ・事実のみを淡々と提示している<br>・評価が含まれる場合でも「仕様書には〇〇と記載されている」と引用の形をとっている |
| **主な原因** | ・LLMの「役に立ちたい」というベースモデルのバイアス（お節介）<br>・System Promptのガードレールが弱い |
| **打ち手** | ・**Prompt**: System Promptでの禁止事項強化（「評価者として振る舞うな」）<br>・**Guardrail**: 出力後のフィルタリング処理 |

---

## 2. デシジョンツリー（対応フロー）

評価でFAILが出た場合、以下の順序で原因を特定し、タスクを割り振る。

1. **検索結果（Source）を見る**
    - **Q:** 正解となる記述（Chunk）が含まれているか？
        - **NO** → **検索改善タスク**（Chunkサイズ変更、キーワード検索追加）
        - **YES** → 次へ

2. **Sourceの内容を見る**
    - **Q:** Sourceの記述自体が矛盾していたり、曖昧だったりしないか？
        - **YES** → **仕様書修正タスク**（ドキュメント担当へチケット発行）
        - **NO** → 次へ

3. **回答生成（Prompt）を見る**
    - **Q:** Sourceはあるのに、無視したり、余計なことを言っているか？
        - **YES** → **プロンプト改善タスク**（指示の明確化、Few-shot追加）

from typing import List, Optional


def detect_fail_type(
    answer: str,
    retrieved_chunks: List[str],
) -> Optional[str]:
    if not retrieved_chunks:
        return "NO_RETRIEVAL"

    if not answer or len(answer.strip()) < 10:
        return "EMPTY_ANSWER"

    for chunk in retrieved_chunks:
        if answer.strip() in chunk:
            return None

    return "HALLUCINATION"

from typing import List

from evaluator.fail_detector import detect_fail_type
from schemas.evaluation import EvaluationResult


def evaluate_answer(
    answer: str,
    retrieved_chunks: List[str],
) -> EvaluationResult:
    fail_type = detect_fail_type(answer, retrieved_chunks)

    if fail_type is None:
        return EvaluationResult(verdict="PASS")

    return EvaluationResult(
        verdict="FAIL",
        fail_type=fail_type,
        reasons=[f"Detected failure type: {fail_type}"],
    )

from __future__ import annotations

from .config import cfg
from .embedder import Embedder
from .llm import run_llm
from .prompt import build_prompt
from .schemas import AnswerResult, Source, Verification
from .utils import (
    _extract_json_object,
    _parse_fallback,
    build_evidence_check_prompt,
    merge_missing_points_into_answer,
)
from .vectorstore import VectorStore


def answer_question(question: str) -> AnswerResult:
    """
    質問を受け取り、RAGを実行し、検証結果を含めた構造化データを返す。
    UI依存（printなど）は一切行わない。
    """
    # 1. インデックスのロード (存在チェックは呼び出し元で行う設計もアリだが、今回は安全のためここで)
    if not cfg.faiss_index_path.exists() or not cfg.meta_path.exists():
        raise FileNotFoundError("Index not found. Run ingest first.")

    vs = VectorStore.load(cfg.faiss_index_path, cfg.meta_path)
    embedder = Embedder()
    q_emb = embedder.embed_query(question)

    # 2. 検索 (Retrieve)
    hits = vs.search(q_emb, cfg.top_k)

    # Sourceオブジェクトのリストに変換
    sources = [
        Source(
            doc_id=h["doc_id"],
            chunk_id=h["chunk_id"],
            text=h["text"],
            score=h.get("score", 0.0),
        )
        for h in hits
    ]

    # コンテキスト作成
    contexts = []
    for s in sources:
        tag = ""
        contexts.append(tag + "\n" + s.text)

    # 3. 回答生成 (Generate)
    prompt = build_prompt(question, contexts)
    initial_answer = run_llm(prompt, contexts)

    # 4. 検証 (Verify)
    check_prompt = build_evidence_check_prompt(question, initial_answer, contexts)
    raw_check = run_llm(check_prompt, contexts)

    try:
        check_data = _extract_json_object(raw_check)
    except Exception:
        check_data = _parse_fallback(raw_check)

    # 検証結果オブジェクトの作成
    verification = Verification(
        verdict=check_data.get("verdict", "insufficient"),
        confidence=float(check_data.get("confidence", 0)),
        missing_points=check_data.get("missing_points", []) or [],
        supported_claims=check_data.get("supported_claims", []) or [],
        unsupported_claims=check_data.get("unsupported_claims", []) or [],
    )

    # insufficientの場合、不足点を回答に追記するロジック
    final_answer = initial_answer
    if verification.verdict == "insufficient":
        final_answer = merge_missing_points_into_answer(
            initial_answer, verification.missing_points
        )

    # 5. 結果のパッキング (Return)
    return AnswerResult(
        question=question,
        answer=final_answer,
        verification=verification,
        sources=sources,
    )

from __future__ import annotations

from pathlib import Path

from .chunking import markdown_header_chunks, simple_char_chunks
from .config import cfg
from .embedder import Embedder
from .vectorstore import VectorStore


def load_docs(docs_dir: Path) -> list[tuple[str, str]]:
    docs: list[tuple[str, str]] = []
    for p in sorted(docs_dir.rglob("*")):
        if p.is_dir():
            continue
        if p.suffix.lower() not in [".md", ".txt"]:
            continue
        text = p.read_text(encoding="utf-8")
        docs.append((str(p.relative_to(docs_dir)), text))
    return docs


def main() -> None:
    cfg.index_dir.mkdir(parents=True, exist_ok=True)

    docs = load_docs(cfg.docs_dir)
    if not docs:
        raise SystemExit(f"No docs found in {cfg.docs_dir}. Put .md/.txt files there.")

    embedder = Embedder()
    all_chunks = []

    for doc_id, text in docs:
        # doc_id は文字列なので、末尾チェックで判定するのが確実です
        if doc_id.lower().endswith(".md"):
            print(f"Chunking Markdown: {doc_id}")
            all_chunks.extend(markdown_header_chunks(doc_id, text))
        else:
            # .txt などの場合は従来の文字数分割（設定値を使用）
            print(f"Chunking Text: {doc_id}")
            all_chunks.extend(
                simple_char_chunks(doc_id, text, cfg.chunk_size, cfg.chunk_overlap)
            )

    texts = [c.text for c in all_chunks]
    # データが空の場合のエラーハンドリング（念のため）
    if not texts:
        print("No chunks generated. Check your docs.")
        return

    embs = embedder.embed_texts(texts)

    vs = VectorStore(dim=embs.shape[1])
    vs.add(embs, all_chunks)
    vs.save(cfg.faiss_index_path, cfg.meta_path)

    print(
        f"Indexed docs={len(docs)} chunks={len(all_chunks)} -> {cfg.faiss_index_path}"
    )


if __name__ == "__main__":
    main()

from dataclasses import dataclass


@dataclass
class Chunk:
    doc_id: str
    chunk_id: int
    text: str


def simple_char_chunks(
    doc_id: str, text: str, chunk_size: int, overlap: int
) -> list[Chunk]:
    text = text.replace("\r\n", "\n")
    chunks: list[Chunk] = []
    i = 0
    cid = 0
    n = len(text)

    while i < n:
        j = min(n, i + chunk_size)
        chunk_text = text[i:j].strip()
        if chunk_text:
            chunks.append(Chunk(doc_id=doc_id, chunk_id=cid, text=chunk_text))
            cid += 1
        if j == n:
            break
        i = max(0, j - overlap)

    return chunks


def markdown_header_chunks(
    doc_id: str, text: str, min_chunk_size: int = 50
) -> list[Chunk]:
    """
    Markdownのヘッダー(#, ##, ###)単位でテキストを分割する。
    単純な文字数分割よりも、文書の構造（文脈）を保持しやすい。
    """
    # 改行コードの統一
    text = text.replace("\r\n", "\n")
    lines = text.split("\n")

    chunks: list[Chunk] = []
    buffer: list[str] = []
    cid = 0

    # Markdownヘッダーを検知する正規表現
    # ^#{1,6}\s は、「行頭に#が1〜6個あり、その後に空白がある」パターン
    header_pattern = re.compile(r"^#{1,6}\s")

    for line in lines:
        # ヘッダー行を見つけた場合
        if header_pattern.match(line):
            # すでにバッファに中身があり、かつ一定サイズ以上ならチャンクとして保存
            # (min_chunk_sizeは、空の改行やゴミ等の微細なチャンク生成を防ぐため)
            if buffer:
                chunk_text = "\n".join(buffer).strip()
                if len(chunk_text) > 0:
                    chunks.append(Chunk(doc_id=doc_id, chunk_id=cid, text=chunk_text))
                    cid += 1
                # バッファをリセット
                buffer = []

            # 新しいセクションの開始（ヘッダー行自体もバッファに入れる）
            buffer.append(line)
        else:
            # 普通の行はバッファに追加し続ける
            buffer.append(line)

    # ループ終了後、バッファに残っている最後のセクションを保存
    if buffer:
        chunk_text = "\n".join(buffer).strip()
        if len(chunk_text) > 0:
            chunks.append(Chunk(doc_id=doc_id, chunk_id=cid, text=chunk_text))

    return chunks

from __future__ import annotations

import json
from dataclasses import asdict
from pathlib import Path

import faiss
import numpy as np

from .chunking import Chunk


class VectorStore:
    def __init__(self, dim: int):
        self.dim = dim
        self.index = faiss.IndexFlatIP(dim)  # cosine相当（正規化済み前提）
        self.meta: list[dict] = []

    def add(self, embeddings: np.ndarray, chunks: list[Chunk]) -> None:
        assert embeddings.shape[0] == len(chunks)
        self.index.add(embeddings)
        for c in chunks:
            self.meta.append(asdict(c))

    def save(self, index_path: Path, meta_path: Path) -> None:
        index_path.parent.mkdir(parents=True, exist_ok=True)
        faiss.write_index(self.index, str(index_path))
        meta_path.write_text(
            json.dumps(self.meta, ensure_ascii=False, indent=2), encoding="utf-8"
        )

    @staticmethod
    def load(index_path: Path, meta_path: Path) -> "VectorStore":
        index = faiss.read_index(str(index_path))
        meta = json.loads(meta_path.read_text(encoding="utf-8"))
        vs = VectorStore(index.d)
        vs.index = index
        vs.meta = meta
        return vs

    def search(self, query_emb: np.ndarray, top_k: int) -> list[dict]:
        scores, idxs = self.index.search(query_emb, top_k)
        results: list[dict] = []
        for score, idx in zip(scores[0], idxs[0]):
            if idx < 0:
                continue
            m = self.meta[idx].copy()
            m["score"] = float(score)
            results.append(m)
        return results

import json
import re
from typing import Any, Dict, List


def _extract_json_object(text: str) -> Dict[str, Any]:
    """
    LLMが前置き/後置きを混ぜても、最初に見つかったJSONオブジェクトを抽出する。
    """
    # まずは全体をそのままJSONとして試す
    try:
        return json.loads(text)
    except Exception:
        pass

    # ```json ... ``` の中身を優先
    fenced = re.search(r"```(?:json)?\s*(\{.*?\})\s*```", text, re.DOTALL)
    if fenced:
        return json.loads(fenced.group(1))

    # 最初の { から最後の } までを雑に抜く（最小実装）
    m = re.search(r"(\{.*\})", text, re.DOTALL)
    if not m:
        raise ValueError("No JSON object found in verifier output.")
    return json.loads(m.group(1))


def _parse_fallback(text: str) -> Dict[str, Any]:
    """
    JSON解析に失敗した場合の救済措置（Fallback）
    テキストから正規表現で無理やり判定（Verdict）を読み取る
    """
    text_lower = text.lower()

    # デフォルトは安全側に倒して insufficient
    verdict = "insufficient"

    # 正規表現で "verdict" : "sufficient/insufficient" のパターンを探す
    match = re.search(
        r"['\"]?verdict['\"]?\s*[:=]\s*['\"]?(sufficient|insufficient)['\"]?",
        text_lower,
    )

    if match:
        verdict = match.group(1)
    else:
        # キーが見つからない場合、単語の出現で推測（最後の手段）
        if "insufficient" in text_lower:
            verdict = "insufficient"
        elif "sufficient" in text_lower:
            verdict = "sufficient"

    return {
        "verdict": verdict,
        "confidence": 10,  # 救済措置なので信頼度は低く設定
        "reasons": ["JSON parse failed, recovered by text fallback logic."],
        "missing_points": ["(Check raw_verifier_json for details)"],
        "supported_claims": [],
        "unsupported_claims": [],
    }

import numpy as np
from sentence_transformers import SentenceTransformer


class Embedder:
    def __init__(self, model_name: str = "sentence-transformers/all-MiniLM-L6-v2"):
        self.model = SentenceTransformer(model_name)

    def embed_texts(self, texts: list[str]) -> np.ndarray:
        # float32でFAISS向け
        emb = self.model.encode(texts, normalize_embeddings=True)
        return np.asarray(emb, dtype="float32")

    def embed_query(self, text: str) -> np.ndarray:
        emb = self.model.encode([text], normalize_embeddings=True)
        return np.asarray(emb, dtype="float32")

import json
import time
from collections import defaultdict

# serviceからロジックを呼ぶ
from ragqa.ask import answer_question

GROUND_TRUTH_PATH = "data/eval/ground_truth.json"
REPORT_PATH = "data/eval/report.json"


def run_evaluation():
    with open(GROUND_TRUTH_PATH, encoding="utf-8") as f:
        cases = json.load(f)

    results = []
    by_type = defaultdict(list)

    print(f"Starting evaluation of {len(cases)} cases...\n")
    start = time.time()

    for i, case in enumerate(cases, 1):
        print(f"[{i}/{len(cases)}] {case['question']} ... ", end="")

        # 1. RAGを実行
        # answer_question() は AnswerResult オブジェクトを返す
        result = answer_question(case["question"])

        # 2. 評価ロジック
        # A: Verdictの一致確認 (sufficient / insufficient)
        # RAGが自分で出した判定(result.verification.verdict) と 正解(expected_verdict) を比較
        verdict_ok = result.verification.verdict == case["expected_verdict"]

        # B: 必須キーワードの確認
        must_include_ok = True
        missing_words = []
        for word in case.get("must_include", []):
            if word not in result.answer:
                must_include_ok = False
                missing_words.append(word)

        # C: 最終判定 (AND条件)
        passed = verdict_ok and must_include_ok

        # 失敗理由の生成
        reasons = []
        if not verdict_ok:
            reasons.append(
                f"Verdict Mismatch: Expected '{case['expected_verdict']}', got '{result.verification.verdict}'"
            )
        if not must_include_ok:
            reasons.append(f"Missing keywords: {missing_words}")

        status = "PASS" if passed else "FAIL"
        print("✅ PASS" if passed else "❌ FAIL")

        # 3. レポート用データの構築 (ここで answer をしっかり保存！)
        results.append(
            {
                "id": case["id"],
                "type": case["type"],
                "question": case["question"],  # 質問
                "result": status,  # PASS/FAIL
                "answer": result.answer,  # 【修正】実際の回答テキストを追加
                "rag_verdict": result.verification.verdict,  # RAGの自己評価
                "expected_verdict": case["expected_verdict"],  # 期待する評価
                "reasons": reasons,  # 失敗理由
                "citations": [  # 引用元情報
                    f"{s.doc_id}#{s.chunk_id}" for s in result.sources
                ],
            }
        )

        by_type[case["type"]].append(passed)

    elapsed = time.time() - start

    # 集計
    summary = {
        "score": sum(r["result"] == "PASS" for r in results) / len(results) * 100
        if results
        else 0,
        "by_type": {t: sum(v) / len(v) * 100 for t, v in by_type.items()},
        "time_sec": round(elapsed, 2),
    }

    report = {"summary": summary, "details": results}

    with open(REPORT_PATH, "w", encoding="utf-8") as f:
        json.dump(report, f, ensure_ascii=False, indent=2)

    print("\n==============================")
    print("Evaluation Complete")
    print(f"Score: {summary['score']:.1f}%")
    for t, s in summary["by_type"].items():
        print(f"{t}: {s:.1f}%")
    print(f"Time:  {summary['time_sec']}s")
    print(f"Report saved to: {REPORT_PATH}")
    print("==============================")


if __name__ == "__main__":
    run_evaluation()
