# エラーコード リファレンス

この文書は仕様書RAGの検索評価向けに作成した合成コーパスです。

## 主要事実
- HTTP 400 は入力バリデーション失敗を表す。
- HTTP 401 は認証失敗または未認証を表す。
- HTTP 403 は権限不足を表す。
- HTTP 404 は対象リソース未検出を表す。
- HTTP 409 は会員登録時のメール重複競合を表す。
- HTTP 422 は意味的に不正な要求を表す。
